# Open questions

Questions without an answer and problems without a chosen fix: the only place
unsettled things live. Decided work lives in ROADMAP. Settled: the why goes to
a decision, the state to its theme doc, and the question leaves this list.

The list is read, never kept: `bun kb question list [--group <group>]`;
`bun kb question add "<title>" --group <group>` records one and
`bun kb question resolve <id> --decision <id>` closes it (`bun kb --help`).
