# Bodies as an ECS

A vehicle, a ship and a thing carried are bodies beside the avatar, each composed of parts: a seat, a thrust, a hold. With one kind of body an ECS is a list, so the crate is chosen with the second kind: `hecs` or `bevy_ecs` standalone. The ground is a function and the cells are grids by address: neither is kept as entities

**Context:** DECISIONS 03, 108.
