# DECISIONS

The log of what was chosen, why, and what was rejected. One file per entry
in `docs/decisions/`, written once; the current state lives in the theme
docs. This index is generated by `bun run docs gen` and checked by
`bun run docs`: edit the entries, never the table.

- **Status**: decided (Marlus said so), proposed (recommended, not yet
  confirmed; confirm or strike before code depends on it), noted (a reading
  of a ref, not a choice), retired (struck title, with the entry that
  replaced it).
- **A new entry** is the next number, in the commit that applies it. Its first
  paragraph is the decision in one breath; then the why, **Rejected**, and
  **Lives in**. The story of how it was reached stays in the commit message.
- **A retired entry** keeps its number and file: its title is struck, with
  the number that replaced it, in the commit that retires it.
- Entries 01 to 25 come from the founding design conversation of 2026-09-20.
