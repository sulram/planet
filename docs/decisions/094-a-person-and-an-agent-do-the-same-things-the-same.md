# 94. A person and an agent do the same things the same way (decided)

Logged 2026-10-04.

What a world offers, it offers to a person and to an agent alike, from the
first plugin on. A capability is a command at the seam, named, with its
parameters said, and whatever a picture shows has a reading that says the same
as data. A tool is how a hand composes a command; an agent sends the command
itself. An agent is an account as a person is: it enters through a door, holds
a level and is given permissions, a volume to build in among them.

**Why from the start.** An editor of ours that takes commands as the only way
to change its document got history, shortcuts, macros and automation as
consequences, and its constraints, held where the command is applied, hold for
a script as for a hand. The fork's agent work shows the other path: a gateway
beside the engine, with a read model of the voxels and actions to place them,
a second surface that follows the first a step behind. Here the seam is that
surface: commands in and events out, JSON tagged by `type`, with tool logic in
Rust behind it. Keeping it whole costs little while there is one plugin to
write, and a retrofit costs every place a panel decided something.

**What it asks of a plugin.** Every op one of its tools makes has a command
that asks for it by its parameters: a stroke is a gesture over a box in a
paint, with a pointer to draw it or without. What it draws it also answers as
a reading: the cells in a box, where an account may build. A refusal is a
code. Its constraints live in its rule, which the server runs, and never in a
panel alone.

**What stays a wish.** The agents themselves: a door of their own in mundos,
perception of what is around a body, building on their own, and a capture, a
picture taken from a pose at low resolution under a permission of its own.
ROADMAP holds them; this entry is what keeps them cheap.

**Rejected:** an API for agents beside the engine, kept in step by hand; a
read model made for agents alone, where one reading serves a panel, a test and
an agent; a rule held by a panel; scripts in world as how an agent, or anyone,
extends it (88).
