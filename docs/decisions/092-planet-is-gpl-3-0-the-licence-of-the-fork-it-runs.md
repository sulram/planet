# 92. planet is GPL-3.0, the licence of the fork it runs beside (decided)

Logged 2026-10-04.

planet's code and docs are under the GNU General Public License, version 3,
chosen by Marlus on the day the repository opened to the public. Whoever
builds on planet and hands the result to someone else hands over its source
too.

**Why GPL.** A world made with planet stays open: a front end, a plugin or a
fork that reaches people reaches them with its source. It is free software,
as VISION asks, and public funding that asks for free software gets the kind
that stays free.

**Why version 3.** It is the licence of the Hyperfy fork that mundos hosts
beside planet, and of the six locomotion clips in the default asset set, which
came from Hyperfy's tree. The code, the docs and those clips stand under one
licence. The avatars are CC0 and the swim clip is Mixamo's; `NOTICE` names
each file with its terms.

**What it opens.** planet's code is written from scratch (01), so the choice
was free. Under GPL-3.0 a ref under a compatible licence, Hyperfy or Veloren,
is code planet may take with its notice; REFS.md decides ref by ref.

**Rejected:** MIT, weighed the same day, which lets a closed product stand on
planet; AGPL-3.0, which also binds whoever runs a changed server for others
and hands out no copy, a step to take if a closed hosted fork ever appears;
publishing with no licence, which lets the code be read and grants nothing
else.

**Lives in:** `LICENSE`, `NOTICE`, README.md § License.
