# 96. The native plugins come in this order: chat, building, land, avatars (decided; land's place proposed)

Logged 2026-10-04.

Chat cuts the host. Building follows it, extracted and kept: a stroke as an op
on the socket, a store by volume, a rule the server runs. Land comes next,
permission by volume over the hook building cut, and is a native plugin from
here on. Avatars close.

**Why building before avatars.** Marlus wants what is built to stay, as a
plugin and in its final shape, before anything else is extracted. The
extraction of avatars hands building nothing it stands on: its seams are a
figure for a body and an offer of avatars, where building's are a turn in the
frame, solids for the footing, the picture, a store and the permission hook
(88).

**Why chat still first.** It is the smallest slice through the server, the
wire, the client and a panel, and it cuts the envelope, the registry and a
panel's place, which building then stands on. A store is cut by building, the
first plugin that keeps things.

**Why land third.** Building cuts the permission hook with the level as its
only answer, and a seam is real with two implementations (65). Land is the
second, and it is what lets a signed in person and an agent build (94, 95).
Marlus asked for it to be in line now, so the hook is shaped with its second
answer in sight.

**Rejected:** the order of 88, avatars before building; saving ahead of the
host, as a log the client replays, which is "works for now"; land left a wish
until building is done, which shapes the hook by one answer.
